### How I work

```
Read the domain first.     Healthcare and hiring both punish engineers who
                           model the schema before they understand the workflow.

Boring where it counts.    Predictable data layers, obvious state, few clever
                           abstractions. Save the novelty for the actual problem.

Retrieval over recall.     An LLM feature is a retrieval problem wearing a
                           costume. Most quality wins are upstream of the model.

Ship, then measure.        A screening tool nobody trusts is worth less than a
                           narrower one they do.
```
