# Publishing this profile

Everything here goes into one special repository: **`t4repo/t4repo`**. GitHub renders the
README of a repo named after your username at the top of your profile page.

## 1. Create the repo

On GitHub: **New repository** → name it exactly `t4repo` → **Public** → don't add a README
(you already have one). GitHub will show a "✨ special repository" note when you type the
name correctly.

## 2. Push these files

```bash
cd path/to/this/folder
git init -b main
git add .
git commit -m "Profile"
git remote add origin git@github.com:t4repo/t4repo.git
git push -u origin main
```

The layout:

```
README.md                              the profile itself
assets/header-light.svg                banner, light theme
assets/header-dark.svg                 banner, dark theme
scripts/build_header.py                regenerates both banners
scripts/refresh_profile.py             regenerates the auto-updated sections
.github/workflows/refresh-profile.yml  runs both, daily
REPO-POLISH.md                         descriptions and topics for your other repos
SETUP.md                               this file
```

## 3. Let the workflow write

Repository **Settings → Actions → General → Workflow permissions** → select
**Read and write permissions** → Save. Without this the daily commit fails with a 403.

Then **Actions → Refresh profile → Run workflow** to populate the generated sections
immediately instead of waiting for the 05:12 UTC schedule.

## 4. Pin your repos

Profile → **Customize your pins** → choose, in this order:

1. `OrderManagementSystem`
2. `library-managment-db`
3. `Thebestoo-ak4yhud-Fully-fixed`
4. `Thebestoo-Fivem-Old-Benny-UI-esx`
5. `thebesto-drugcreator`

Order matters — GitHub shows pins left to right, and the first two are the ones that read
as engineering rather than modding.

## 5. Update your account bio

Your bio is currently `"Fail again. Fail better." | "chase yo dream $& dream big"`. It is
the first line a recruiter or client reads, above everything else on the page, and it
undercuts the rest. Replace it (**Settings → Public profile → Bio**) with something like:

> Software engineer — AI retrieval systems and healthcare platforms. Building RetrieveHR.

Also fill in **Location** (`Prishtina, Kosovo`) and **Company** — both are empty, and the
location field is what makes you appear in regional searches.

Set your display name to `Diar Azemi` rather than `DiarAz t4repo`.

## Changing things

**Your name, role, or the banner text** — edit the constants at the top of
`scripts/build_header.py`, then `python scripts/build_header.py`. Both themes regenerate
together, so they can never drift apart.

**Colours** — the `THEMES` dict in the same file. The light and dark backgrounds are set to
`#ffffff` and `#0d1117` on purpose: those are GitHub's own canvas colours, so the banner
has no visible edge and reads as part of the page rather than a pasted image.

**The motif** — the dot field on the right is a 2-D embedding space: one query vector, its
five nearest neighbours, and the retrieval radius, with a slow pulse on the query. It is a
picture of what RetrieveHR actually does. `random.seed(1987)` fixes the layout; change the
seed for a different arrangement, or `neighbours = rest[:5]` for a different fan-out.

**The language bar** — worth a decision. It is honest, self-hosted, and currently reports
roughly half Lua, because your public code is FiveM work. Under an "AI retrieval systems"
headline that is a slightly awkward number. Two reasonable choices: leave it, and let the
caption do its job; or delete the `<!-- LANGS:START -->` / `<!-- LANGS:END -->` block from
`README.md` and bring it back once you have published AI work. The script skips any marker
it can't find, so removing the block is safe.

**Turning the automation off** — delete `.github/workflows/refresh-profile.yml`. The README
keeps whatever text was last written into it.

## What this does not use

No `github-readme-stats`, no streak-counter services, no visitor-count badges, no trophy
images. Those are third-party servers rendering images into your profile: they rate-limit,
break, go down, occasionally get taken over, and they make every profile using them look
identical. Everything on this profile is generated by a script in your own repository from
your own data, committed as plain text you can read in a diff. That is the part that reads
as professional.
